# AG-DISTILL-T2B 证据缺口登记 — WHE-02 小麦赤霉病候选单元

- 登记范围：T2B 全量复核后，候选单元中**若无真实证据/文本则不可升级为可发布知识**的主张。
- 纪律：本登记按"期待证据的形状"描述，不提供出处清单/文件编号（出处检索由人工证据责任人执行）；agent 复核不产生证据。
- 门禁关系：P1 五条合规门禁未闭合前，相关单元不得用于决策型回复（拒收判定、合规测算、处置建议）。

## 优先级 1：合规/标准文本（阻塞 P1 门禁）

1. **DON/ZEN 现行限量标准文本**：期望证据为"某一日发布的人食用小麦及其制品中 DON/ZEN 限值条款原文"。
   绑定单元：WHE02-Q-04、WHE02-K-02（AUD-T2B-035 / AUD-T2B-022）。
2. **小麦收购质量标准"病粒率"条款**：期望证据为现行收购质量标准中病粒率分级的原文条款（含分级界限与适用品类）。
   绑定单元：WHE02-Q-05（AUD-T2B-036）。
3. **农药登记标签集合**：期望证据为"标签登记对象含小麦赤霉病"的具体药剂的标签页，含安全间隔期、施药时期、抗性治理提示。
   绑定单元：WHE02-R-07、WHE02-Q-06、WHE02-R-03（AUD-T2B-019 / AUD-T2B-037 / AUD-T2B-014）。

## 优先级 2：田间/流行学数据（P1 实质性主张 + P2）

4. **区域病原分离监测**：期望证据为"赤霉病复合种优势组成（含茎基腐/秆腐病原构成）"的分离鉴定数据，用于重申或收敛 D-03 同一性主张并支撑 D-01/D-04 层级表述。
   绑定单元：WHE02-D-01、WHE02-D-03、WHE02-D-04（AUD-T2B-001 / AUD-T2B-003 / AUD-T2B-005）。
5. **流行学条件依赖实证**：期望证据为"在某关键要素缺失/弱化的年份流行程度变化"的观察或试验数据（D-09 反例边界）。
   绑定单元：WHE02-D-09（AUD-T2B-010）。
6. **分期施药试验/防效贴现数据**：期望证据为"扬花后不同时点补治的防效、DON 差异"的分组试验数据。
   绑定单元：WHE02-R-08、WHE02-Q-06、WHE02-Q-07 的份额部分（AUD-T2B-020 / AUD-T2B-037）。
7. **区域降雨规律与播期产量代价**：期望证据为"区域播期-灌浆期降雨重叠概率"及晚播产量损失的区域数据。
   绑定单元：WHE02-R-06（AUD-T2B-018）。

## 优先级 3：标准/规范文本（维持 null 门禁即可，不阻塞发布层级）

8. **区域气象预警模型阈值**（Q-01、R-02、F-02 的"菌源低/花后有雨"信息前提）。
9. **测报调查规范病穗率/病情指数分级**（Q-02）。
10. **储粮安全水分界限与储存期 DON 增长数据**（Q-08、Q-09、F-06）。
11. **病穗率-DON 本地回归数据**（Q-03、K-01、K-03）。
12. **品种耐病性判定口径**（F-04；当前无 null 阻塞，属可选加固）。

## 明确不是缺口的项

- 20 行 no-issue 单元维持候选；升级证据等级一律通过 T2C 门禁，不让 agent 复核顶替证据。
